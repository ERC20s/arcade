Add a game to this launcher

Each game lives in its own folder: games/<name>/index.html, a single self-contained file (inline CSS/JS, no build step, no external dependencies) of at most 400 lines.

A minimal starting point is available at template/game-template/index.html; copy it into your new game folder and edit the metadata block and code. See CONTRIBUTING.md for the full checklist (required metadata header, keyboard + touch controls, score display, pause overlay).

Once your game is merged, add one line to the list above: <a class="game" href="games/<name>/index.html">Title — one-line description</a>
